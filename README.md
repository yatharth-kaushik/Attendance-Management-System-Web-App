## 📖 Overview

**Attendance Management System (AMS)** is a simple, user-friendly web app that makes managing student attendance easy. Manage student records, mark attendance, track it **subject by subject**, view attendance history and calculate attendance percentages.

Built with **HTML, CSS and JavaScript**, it saves everything in the browser using **localStorage**, so **no backend or external database is needed**.

## 🚀 Getting Started

**1️⃣ Clone the repository**

```bash
git clone https://github.com/yatharth-kaushik/Attendance-Management-System-Web-App.git
```

**2️⃣ Open the project folder**

```bash
cd Attendance-Management-System-Web-App
```

**3️⃣ Run the app**

Open `index.html` in your web browser.

> 🎉 That's it! No installation or setup is required.

---

## 💡 How It Works

1. ➕ Add student records to the system
2. 📚 Select the required subject
3. ✅ Mark students as **Present** or **Absent**
4. 💾 Save the attendance record
5. 🔍 View individual or subject-wise attendance records
6. 📊 Check attendance percentages and history
