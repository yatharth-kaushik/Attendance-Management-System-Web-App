# 🎓 Attendance Management System (AMS)

A simple and user-friendly **web-based Attendance Management System** designed to simplify the process of managing student attendance. The application allows users to manage student records, mark attendance, track subject-wise attendance, view attendance history, and calculate attendance percentages.

Built using **HTML, CSS, and JavaScript**, the application uses **localStorage** to store data directly in the browser without requiring a backend or external database.

---

## 🚀 Features

* 👨‍🎓 **Student Management**

  * Add and manage student records.
  * Organize student information efficiently.

* ✅ **Attendance Marking**

  * Mark students as **Present** or **Absent**.
  * Easily record daily attendance.

* 📚 **Subject-Wise Attendance**

  * Track attendance separately for different subjects.
  * Maintain organized attendance records.

* 👤 **Individual Student Records**

  * View attendance details for individual students.
  * Check personal attendance history and statistics.

* 📊 **Automatic Percentage Calculation**

  * Calculate overall attendance percentage.
  * Track subject-wise attendance percentages.

* 📅 **Attendance History**

  * Maintain records of previously marked attendance.
  * Easily access attendance information.

* 💾 **Local Data Storage**

  * Uses **localStorage** to save data in the browser.
  * No backend or external database required.

* 📱 **Responsive User Interface**

  * Simple and clean interface.
  * Designed to work across different screen sizes.

## 🛠️ Tech Stack

* **HTML5** – Structure of the application

## 💡 How It Works

1. Add student records to the system.
2. Select the required subject.
3. Mark students as **Present** or **Absent**.
4. Save the attendance record.
5. View individual or subject-wise attendance records.
6. Check attendance percentages and history.
